欢迎来到我的博客!🎉

这是我用 [Hexo](https://hexo.io/) + [Butterfly](https://github.com/jerryc127/hexo-theme-butterfly) 主题搭建的个人博客,托管在 GitHub Pages 上。

## 我会在这里写什么

- 📝 学习笔记
- 💻 技术分享
- 🌱 生活记录

## 快速开始写作

在命令行输入以下命令即可创建新文章:

```bash
hexo new post "文章标题"
```

文章保存在 `source/_posts/` 目录下,写完提交到 GitHub,博客会自动更新。
